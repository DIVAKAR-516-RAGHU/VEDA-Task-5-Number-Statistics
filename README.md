## Task 5 – Number Statistics

### Objective

Create a Python program to identify even and odd numbers and find the largest and smallest numbers in a given list.

### Tools Used

* Python
* Jupyter Notebook

### Input Data

```text
[12, 7, 25, 4, 18, 9, 30, 11, 6, 21]
```

### Approach

1. Create a list of numbers.
2. Use a `for` loop to process each number.
3. Use the modulo operator `%` to identify even and odd numbers.
4. Store even and odd numbers in separate lists.
5. Use `max()` to find the largest number.
6. Use `min()` to find the smallest number.

### Results

**Even Numbers:**

```text
[12, 4, 18, 30, 6]
```

**Odd Numbers:**

```text
[7, 25, 9, 11, 21]
```

**Largest Number:** `30`

**Smallest Number:** `4`

### Concepts Practiced

* Python Lists
* For Loops
* If-Else Conditions
* Modulo Operator `%`
* `append()`
* `max()`
* `min()`

### Conclusion

The program successfully separates the given numbers into even and odd lists and identifies the largest and smallest values using basic Python programming concepts.
